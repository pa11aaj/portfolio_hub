# Parimala Alva ---> Portfolio Hub

This is a single static site (no build step, no framework, no dependencies) — the "hub" site for my
resume portfolio: qualifications, experience, skills, a tabbed projects section, and contact info, all in one page.

```
portfolio-hub/
├── index.html
├── styles.css
├── script.js
├── assets/
│   ├── parimala-photo.jpg
│   └── Parimala_Alva_Resume.pdf
└── README.md
```

Because it's plain HTML/CSS/JS with zero build step, there is nothing to install and nothing
that can fail during a Vercel build. The project is live on Vercel and links to all other AI-enablement
projects that I have built and are available on Github.
