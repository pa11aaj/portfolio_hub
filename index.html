AI SDLC Coach

A mode-switching LangChain agent: code reviewer and solution architect tutor, in one.

A LangChain tool-calling agent with two personas sharing one prompt-engineering discipline and one Pydantic-validated output contract. The Code Reviewer runs real static analysis (bare excepts, mutable defaults, possible SQL injection, cyclomatic complexity) before producing severity-ranked findings. The Architecture Tutor retrieves grounded trade-offs from a local knowledge base and always ends in guiding questions instead of a flat verdict. Ships with a framework-optional offline backend (fully testable without an API key), a full test suite, and a recorded reasoning transcript.
