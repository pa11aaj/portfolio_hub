AI Onboarding Engineer

A LangGraph agent that turns any document set into a hands-on, self-paced onboarding course.

Runs as a three-step pipeline — design a syllabus, generate a lab, then review the learner's answer — with each step retrieving grounded context from a Pinecone vector store, so lessons, quizzes, and reference sheets stay traceable back to real source material rather than the model's own guesses. Every step produces a short-answer challenge, a 4-option auto-graded quiz, and a downloadable cheat-sheet together, using structured, validated outputs instead of free-form text. Session state lives in Postgres, so the whole app runs as stateless serverless functions on Vercel — point the ingestion pipeline at any docs or codebase, and it becomes the material learners are onboarded against.

  • LangGraph
  • RAG
  • Pinecone
  • PostgreSQL
  • Vercel
  • Python

AI Skills Navigator & L&D Ops Assistant

A rule-based web app that automates AI training plans, learner support, and feedback triage for L&D teams.

Automates three time-consuming L&D jobs: builds each employee a personalized 30/60/90-day AI training plan based on department and comfort level, answers learner questions about schedules, prerequisites, and credits instantly through a built-in chatbot, and turns uploaded survey feedback into a sentiment summary with a short list of action items. Learners get faster, more consistent guidance, and coordinators get back the hours they used to spend on manual planning and feedback review. Built with Next.js (App Router) and TypeScript, styled with Tailwind CSS, using simple rule-based logic instead of an external AI API — so it needs no key or setup — and deploys straight to Vercel.

  • Next.js
  • TypeScript
  • Tailwind CSS
  • Vercel
